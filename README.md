# AI 기반 문맥 감지형 자동 영상 편집 플랫폼

OpenAI Whisper와 GPT-4o-mini를 활용한 지능형 영상 편집 파이프라인입니다.

## 기능

- 🎤 **음성 인식**: Whisper API로 한국어 음성을 텍스트로 변환 및 타임스탬프 추출
- 🧠 **문맥 분석**: GPT-4o-mini가 영상 내용과 감정을 분석하여 최적의 편집 전략 생성
- ✂️ **스마트 컷 편집**: 문맥에 따른 자동 컷 편집 (무음 구간 제거 등)
- 🎨 **스타일 프리셋**: 3가지 편집 스타일 지원
- 📝 **자동 자막 생성**: 한국어 자막 자동 합성

## 스타일 프리셋

### 🌶️ 매운맛 (예능/숏폼)
- 오디오 공백 적극적으로 제거
- 크고 화려한 자막 (40-50px)
- 역동적인 편집

### 🍲 순한맛 (브이로그)
- 최소한의 컷 편집으로 자연스러운 호흡 유지
- 차분한 자막 스타일 (30-35px)
- 감성적인 분위기

### 🍚 정석맛 (지식/정보)
- 말버릇과 불필요한 공백만 제거
- 가독성 중심 자막 (28-32px)
- 전문적인 느낌

## 설치

### 1. 라이브러리 설치
```bash
pip install -r requirements.txt
```

### 2. Gemini API 키 설정

#### 방법 1: 자동 설정 (추천)
```bash
python main.py
```
프로그램이 자동으로 API 키 설정을 안내합니다.

#### 방법 2: 환경 변수 설정
```bash
export GEMINI_API_KEY="your_gemini_api_key_here"
```

#### 방법 3: 파일에 직접 저장
`api_key.txt` 파일을 만들어 API 키를 입력하세요.

### 📋 API 키 발급 방법
1. [Google AI Studio](https://aistudio.google.com/app/apikey) 접속
2. "Create API Key" 클릭
3. 새 프로젝트 생성 또는 기존 프로젝트 선택
4. 발급된 API 키 복사

## 사용법

### 1. 영상 파일 준비
현재 디렉토리에 `input.mp4` 파일을 넣어주세요.

### 2. 프로그램 실행
```bash
python main.py
```

### 3. 스타일 선택
```
🎨 스타일 프리셋을 선택하세요:
1. 매운맛 (예능/숏폼)
2. 순한맛 (브이로그)
3. 정석맛 (지식/정보)
선택 (1-3):
```

### 4. 결과 확인
`output.mp4` 파일로 편집된 영상이 생성됩니다.

## 파이프라인 과정

1. **Step 1**: 영상에서 오디오 추출
2. **Step 2**: Whisper API로 음성 인식 및 타임스탬프 추출
3. **Step 3-4**: GPT-4o-mini로 문맥 분석 및 편집 명령어 생성
4. **Step 5**: 최종 영상 생성 (컷 편집 + 자막 합성)

## 시스템 요구사항

- Python 3.8+
- macOS (기본) / Windows / Linux
- OpenAI API 접근 권한
- 최소 2GB RAM (영상 크기에 따라 다름)

## 폰트 설정

- **macOS**: AppleGothic (기본)
- **Windows**: Malgun Gothic (경로 수정 필요)
- **Linux**: NanumGothic (경로 수정 필요)

코드 내 `KOREAN_FONT_PATH` 변수를 수정하여 폰트 경로를 변경할 수 있습니다.

## 주의사항

- 인터넷 연결 필요 (OpenAI API 호출)
- 긴 영상의 경우 처리 시간이 오래 걸릴 수 있음
- API 사용량에 따라 비용 발생 가능성

## 에러 해결

### 영상에 오디오가 없을 경우
```
ValueError: 영상에 오디오 트랙이 없습니다.
```
오디오가 포함된 영상 파일을 사용해주세요.

### OpenAI API 키 오류
```
❌ OPENAI_API_KEY 환경 변수를 설정해주세요.
```
환경 변수가 올바르게 설정되었는지 확인해주세요.

### 한국어 폰트 깨짐
`KOREAN_FONT_PATH` 변수를 시스템에 맞는 한국어 폰트 경로로 수정해주세요.
