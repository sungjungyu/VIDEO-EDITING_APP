# 받아쓰기 엔진 비교 (1차, 2026-10-11)

작성: 권용관 · 담당표 1단계 1차 "받아쓰기 비교 후 교체, 단어 타임스탬프 출력"

## 결론

**Gemini(`gemini-3.5-transcribe`)를 기본 엔진으로 제안한다.** 로컬 Whisper보다 15배 빠르고, 글자·단어 시각 모두 더 정확하며, 문장을 빼먹지 않았다.
로컬 Whisper는 API를 못 쓸 때의 예비 엔진으로 남긴다. Whisper API(OpenAI)는 유료라 이번 비교에서 보류했다.

## 비교 방법

- 같은 7개 클립(총 3분 13초)을 두 엔진으로 `transcriber.py`에 돌리고 `stt_compare.py`로 표를 만들었다.
  - TTS로 만든 한국어 문장 클립(카페·성수), 같은 문장에 배경 소음을 섞은 클립 2개(-30dB, -20dB),
    소음만 있는 클립, 오디오 없는 클립, 2분 12초 클립(10문장 × 3회 반복)
- 정답: TTS에 넣은 원문 / 실제 말소리 구간: 소음 없는 원본에서 측정
- 실제 촬영본(사람 목소리, 여러 명, 현장 소음)이 아니므로 숫자는 참고용이다. 촬영본이 나오면 같은 방법으로 다시 잰다.

## 발견한 것

1. **로컬 Whisper가 문장 두 개를 통째로 빼먹었다.** 2분 클립의 두 번째 반복에서 "영상 끝까지 시청해 주시고 구독과 좋아요 부탁드립니다. 다음 영상에서 또 만나요."(7초)가 결과에 없다.
   글자 오류율 4.4%와 최대 경계 오차 3.67초가 대부분 이 때문이다. 말한 내용이 조용히 사라지는 오류라 편집에서 위험하다.
   (설정 없이 Whisper를 직접 돌렸을 때는 빠지지 않았다. main.py에서 가져온 `initial_prompt`·`condition_on_previous_text` 설정의 영향으로 보인다.)
2. **Whisper는 소음만 있는 구간에서 안내 문구를 지어낸다.** 환각 필터로 제외됨. Gemini는 아무것도 출력하지 않았다.
3. **Gemini는 문장 단위로 나눠 준다** (단어 + 문장부호 기준). Whisper는 2~3문장을 한 덩어리로 묶는다. 4단 트리의 "대사" 층과 자막 줄에는 Gemini 쪽이 맞다.
4. **Gemini 단어 시각은 대체로 정확하지만 가끔 크게 틀린다.** 문장 첫 단어 시작을 10초 앞당긴 경우가 있었다.
   → 정리 단계(끝 시각 순 정렬)와 무음 보정에서 바로잡고, 3초 넘는 단어는 검증 경고로 표시한다.
5. **Gemini 결과는 기본 설정(temperature 1.0)에서 실행마다 조금씩 다르다.** → temperature 0으로 고정. 고정 후 두 번 실행 결과가 같았고 2분 클립 오류도 0개였다.
   (위 표의 Gemini 행은 고정 전에 받은 결과다. "맑아서"를 "말라서"로 쓴 1글자가 0.3%.)
6. **무료 키는 `gemini-3.5-transcribe`를 하루 25번까지만 부를 수 있다.** 10분 단위로 보내므로 하루 약 4시간 분량. 실제 촬영본(얼굴·목소리)은 유료 키 권장.
7. 무음 보정 효과: Whisper는 평균 경계 오차 0.34초 → 0.14초로 크게 줄었고, Gemini는 원래 정확해서 최대값만 줄었다(0.09 → 0.06초).

## 팀에 정할 것

- 기본 엔진 Gemini로 확정할지
- 팀 공용 유료 키를 쓸지 (무료 하루 25회 한도, 실제 촬영본 개인정보)
- Whisper API 비교를 할지 (OpenAI 유료, 최소 충전 필요)

## 다시 재는 방법

```powershell
python transcriber.py --input .\raw_clips --engine whisper-local --out whisper.json
python transcriber.py --input .\raw_clips --engine gemini --out gemini.json
python stt_compare.py whisper.json gemini.json --ref ref.json --truth truth.json --out docs\stt_비교.md
```

`ref.json`(직접 받아쓴 정답)과 `truth.json`(실제 말소리 구간) 형식은 `stt_compare.py` 맨 위 설명 참고.
