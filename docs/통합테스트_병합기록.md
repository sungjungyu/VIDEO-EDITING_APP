## 추가 병합: main af11b8c (성준규가 kyeongwoo를 main에 합침, 10/11 14:55)

kyeongwoo 내용은 이미 이 브랜치에 있어서 파일 변화는 없다. 같은 두 파일이 다시 충돌했고 **이 브랜치의 정리본을 유지**했다.
지금 main은 아래 두 문제로 실행되지 않는다 (확인함):

| 파일 | main의 상태 | 증상 | 고치는 방법 (택1) |
| --- | --- | --- | --- |
| `media_engine/ass_generator.py` | `from .style_presets import get_preset` — 그런데 `style_presets.py`는 refactor에서 삭제됨 | `import media_engine` 실패 → `python app.py` 시작 불가 | ① refactor 버전(DEFAULT_STYLE)으로 되돌리기 ② `style_presets.py`를 다시 살리기 (스타일 설정 기능을 쓰려면 ②) |
| `main.py` `_build_local_commands` | 정의는 `(segments, style_preset)`, 호출은 `(segments)` | Gemini 실패 시 대체 처리에서 TypeError | 정의에서 `style_preset` 인자 제거 (본문은 이미 쓰지 않음) |

→ 성준규·조경우 확인 필요. 자막 스타일 설정을 살릴지(②) 단순화할지(①)는 렌더 담당(성준규)이 정할 일.

## 알려진 한계 (이 브랜치에서)

- **자막 스타일 패널 설정이 렌더에 반영되지 않는다.** 신정빈 화면은 렌더 요청에 `style_overrides`를 보내지만, main 백엔드는 이 값을 받지 않고 기본 스타일(DEFAULT_STYLE)로 렌더한다. 오류는 나지 않는다.
- **성준규 refactor의 "미사용 UI 숨김"이 신정빈 화면에는 적용되지 않았다.** 신정빈 화면은 refactor 이전 화면을 바탕으로 만들어졌다.
  → 정식으로 main에 합치려면 신정빈 화면을 최신 main 위에서 다시 맞추는 작업이 필요하다 (신정빈·성준규).
- 편집 설정 화면의 트리는 아직 가짜 데이터(`FAKE_RAW_TREE`)다. 실제 영상으로 만든 트리 JSON이 필요하다.
- 받아쓰기(transcriber.py)는 아직 앱에 연결하지 않았다. 앱의 분석은 기존 main.py 파이프라인(로컬 Whisper)을 그대로 쓴다.
