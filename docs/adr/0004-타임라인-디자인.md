# ADR 0004 — 타임라인을 영상 편집 프로그램 방식으로 다시 만든다

- 상태: 채택 (2026-10-27)
- 결정한 사람: 성준규, 검토 필요: 신정빈(화면)
- 관련: [ADR 0003](0003-계층-구조와-최적화.md) (화면 폴더 구조)

## 배경

예전 타임라인은 다음과 같은 문제가 있었다.

- 높이 198px 고정, 트랙은 영상·자막 둘뿐이었다.
- 잘린 곳이 클립 아래 6px 파란 줄로만 보였다.
- 자막 칸이 좁으면 글자가 깨졌고, 클릭 한 번에 바로 잘라서 실수하기 쉬웠다.
- 도구 막대·시각 표시·결과 영상 기준 보기가 없었다.
- 바뀔 때마다 DOM 전체를 다시 만들었다.

## 결정 — 시중 영상 편집 프로그램(Premiere·Resolve·Final Cut·CapCut)의 방식을 따른다

| 항목 | 결정 | 근거 |
| --- | --- | --- |
| 처음 보기 | **편집본**(결과 영상 시간축). 원본 보기는 전환해서 본다 | 네 프로그램 모두 타임라인 = 시퀀스(결과), 원본은 따로 본다 |
| 트랙 | 위에서부터 **C1 자막 · T1 텍스트(제목·촬영지) · V1 영상 · A1 소리** | Premiere: 캡션 트랙이 맨 위, 텍스트는 영상 위, 소리는 아래 |
| 장면 | 트랙 대신 눈금 위 **구간 마커**(장소 · 일) | Premiere·Resolve의 시퀀스 마커 |
| 소리 파형 | 넣는다. API `GET /api/projects/{pid}/clips/{cid}/waveform` 추가 (20ms마다 가장 큰 소리, 분석과 같은 오디오 캐시 사용) | 네 프로그램 모두 오디오 트랙에 파형을 그린다 |
| 자막 칸 조작 | 클릭 = 선택, Shift/Ctrl+클릭 = 범위/추가, 더블클릭·Enter = 글자 고치기, Delete = 자르기, Shift+E = 사용/사용 안 함, 오른쪽 클릭 = 메뉴 | Premiere의 선택·Enable(Shift+E)·삭제 동작 |
| 단축키 | Space, J·K·L, ←/→ 프레임, Home/End, + / - / \ 확대·전체 보기, S 붙기, [ ] 이전·다음 잘린 곳 | Premiere 기본 단축키와 같게 (J는 거꾸로 재생 대신 1초 뒤로: 브라우저 영상은 거꾸로 재생을 지원하지 않음) |
| 분위기 | 전문가 배치(트랙 머리·타임코드·얇은 선) + CapCut식 큰 재생 버튼·둥근 클립·말풍선 재생 헤드 | 요청: 두 분위기의 중간 |

## 화면 요소

- **편집본 보기:**
  - 남는 구간을 이어 붙인다.
  - 같은 클립 안에서 잘라 낸 이음매에 ✂ 표시를 둔다. 누르면 그 자리에서 잘린 문장을 보고 바로 살릴 수 있다.
- **원본 보기:**
  - 잘린 곳을 빗금과 빨간 윗선으로 표시하고 이유를 함께 쓴다(NG · 군더더기 · 지시어 · 쉼 · 고르지 않음).
  - 자른 문장은 점선과 취소선으로 보인다.
- **트랙 머리:**
  - 접기, 잠금(V1·C1), 높이(작게·보통·크게)를 고를 수 있다.
  - 설정과 패널 높이는 브라우저에 기억한다.
- **재생 헤드·붙기:** 재생 헤드에 시각 말풍선을 단다. 붙기 안내선을 보여 주고, Alt를 누르고 끌면 붙기를 잠깐 끈다.
- **미리보기 연동:** 미리보기의 [원본]/[편집본] 버튼과 타임라인 보기가 함께 바뀐다.

## 구현

`web/js/panels/timeline/`

| 파일 | 하는 일 |
| --- | --- |
| `model.js` | 두 보기의 시간 변환·잘린 곳·이음매·눈금·붙기. 순수 함수라 `tests/js/timeline-model.test.mjs`로 검사 |
| `state.js` | 트랙 정의·설정 기억 |
| `index.js` | 그리기 예약·트랙 머리·재생 헤드·미리보기 연동 |
| `interact.js` | 확대·스크롤·훑어보기·클립 이동·앞뒤 자르기·붙기·높이 조절 |
| `edit.js` | 선택·단축키·메뉴·글자 고치기·이음매 |
| `ruler.js` · `toolbar.js` · `tracks/*` | 눈금, 도구 막대, 트랙별 그리기 |

성능:

- 눈금·필름 띠·파형·빗금은 화면에 보이는 폭만큼의 캔버스에 그린다.
- 자막 칸은 보이는 범위만 DOM으로 만든다.
- 다시 그리기는 화면 갱신 주기에 한 번, 바뀐 부분(전체 / 스크롤 / 재생 헤드)만 한다.
- 선택은 다시 그리지 않고 표시만 바꾼다(더블클릭이 끊기지 않게).
- 클릭 이벤트는 트랙 단위로 받는다.

## 확인

- Edge 실제 조작 점검 23항목 모두 통과, 콘솔 오류 없음. 확인한 조작은 다음과 같다.
  - 처음 보기, 자르기·되돌리기, 사용/사용 안 함, 글자 고치기
  - 이음매에서 살리기
  - 프레임·초 이동, 시각 입력, 다음 잘린 곳
  - 미리보기 연동, 붙기, 확대, 훑어보기
  - 트랙 설정·패널 높이 기억, 잠금, 앞뒤 자르기, 메뉴로 재생
- 업로드 → 분석 → 검토 → AI 가편집 → 미리보기 → 렌더 전체 흐름도 오류 없음.
- 서버 테스트 104개 통과. OpenAPI 골든은 파형 엔드포인트 1개 추가만 반영했다.
