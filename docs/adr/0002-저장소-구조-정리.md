# ADR 0002 — 저장소 구조 정리: src 레이아웃, pyproject 일원화, 지난 문서는 docs/archive

- 상태: 채택 (2026-10-27), 패키지 안쪽 구조는 [ADR 0003](0003-계층-구조와-최적화.md)으로 대체
- 결정한 사람: 성준규, 검토 필요: 조경우·권용관·신정빈

## 배경

v3에서 앱은 `vibecut` 패키지 하나로 합쳐졌지만, 루트에는 v1·v2 시절 파일과 실행 중 생긴 파일이 섞여 있었다.

| 종류 | 파일 | 문제 |
| --- | --- | --- |
| 엔진 원본 | `transcriber.py`, `scene_analyzer.py`, `scene_tree.py` | 패키지가 루트 모듈을 `import transcriber`처럼 불러 씀 (루트에서 실행해야만 동작). 린트 예외 |
| v3가 대체한 코드 | `scene_selector.py`, `prompt_builder.py`, `test_prompt_builder.py`, `config.py` | 앱에서 쓰지 않음. 키 읽기 규칙이 `vibecut.settings`와 따로 놂 |
| 실험 | `experiment.py`, `experiment_results.json`, `stt_compare.py` | 진입점과 섞여 있음 |
| 진입점·설정 | `app.py`, `main.py`, `requirements*.txt` 3개 | 의존성 목록이 세 파일에 흩어짐 |
| 실행 산출물 | `uploads/`, `outputs/`, `__pycache__/`, `*.log`, `gemini_key.txt` | 루트를 어지럽힘 |
| 문서 | 기획서 8개, 실행 가이드 2개, v1 README | 루트 README가 v1(MoviePy) 기준이라 현재 코드와 다름 |

## 결정

- **src 레이아웃**: 패키지를 `src/vibecut/`에 두고 `pip install -e .`로 설치한다. 루트에서 우연히 import되는 일이 없고, 테스트가 설치된 패키지를 검사한다
- **진입점은 패키지 안 + 명령으로**: `main.py` → `vibecut.cli` (명령 `vibecut`), `app.py` → `vibecut.server.app:run` (명령 `vibecut-server`). `python -m vibecut`, `python -m vibecut.server`도 된다
- **의존성은 pyproject.toml 하나**: `requirements*.txt` 대신 `dependencies`(고정 버전)와 선택 묶음 `[dev]`, `[whisper]`
- **화면은 `web/`**: 백엔드(`src/`)와 프론트엔드(`web/`)를 최상위에서 나눈다. 브라우저 주소(`/static/…`)는 그대로
- **비밀 값은 `.env`**: `.env.example`을 복사해 쓴다. 예전 `gemini_key.txt`도 계속 읽는다
- **엔진은 `vibecut/ai/engines/`로**: `transcriber`, `scene_analyzer`(단독 CLI가 있음). CLI가 없고 어댑터만 감싸던 `scene_tree`는 `ai/tree.py`에 합친다. 엔진 안에 따로 구현돼 있던 ffmpeg 실행·오디오 추출·공백 제거·LLM JSON 파싱은 앱 공용 함수(`vibecut.media.ffmpeg`, `vibecut.edit.text`, `vibecut.ai.gemini`)를 쓴다
- **모듈 크기 맞추기**: 함수 하나뿐이고 한 곳에서만 쓰던 `render/compile.py`+`render/renderer.py`, `edit/validate.py`(planner에 의존)는 합친다. 엔드포인트 23개가 한 파일(495줄)에 있던 `server/api.py`는 `server/api/` 패키지(projects·editing·render 라우터 + common)로 나눈다
- v3가 대체한 코드·실험 스크립트는 지운다 (git 이력에 남음). 비교 도구 `stt_compare.py`만 `scripts/`로
- 지난 기획서·가이드·v1 README는 **내용을 고치지 않고** `docs/archive/`로 옮긴다
- 파일별 린트 예외를 없앤다. 테스트 보조 코드·공용 데이터는 `tests/fixtures/`에 모은다

## 결과

```
.github/  docs/  scripts/  src/vibecut/  tests/  web/
.env.example  .gitignore  pyproject.toml  README.md
```

- 기능은 그대로: 테스트 93개 통과 (`prompt_builder` 호환 테스트 1개는 모듈과 함께 삭제), `ruff check .` 예외 없이 통과, 웹 서버·CLI 실행 확인
- 바뀐 명령: `python app.py` → `vibecut-server`, `python main.py …` → `vibecut …`, `pip install -r requirements.txt` → `pip install -e ".[dev]"`, `python transcriber.py …` → `python -m vibecut.ai.engines.transcriber …`
- 처음 받는 사람은 `pip install -e ".[dev]"`를 한 번 해야 한다 (설치하지 않으면 `vibecut` 명령과 import가 없다)
